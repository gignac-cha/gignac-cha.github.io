# 검수

[목차로](../GUIDELINES.md)

장면을 마무리하기 전에, 장면의 모든 단계를 하나씩 멈춰 놓고 확인한다. 전환 중간의 순간도 함께 본다.

## 내용

- [ ] 장면으로 만들 만한 구간인가? 글자만 있는 구간은 아닌가? ([무엇을 시각화할까](selection.md))
- [ ] 보여 준 값과 사례에 모두 출처가 있는가? 지어낸 값은 없는가?
- [ ] 설명용 연출에는 연출이라는 표시가 있는가?
- [ ] 그래프의 축이 원 자료가 잰 것과 같은 뜻인가?
- [ ] 움직임이 실제 원리와 같은 방향, 같은 순서로 일어나는가?
- [ ] 2D와 3D 선택이 대상의 본래 차원과 맞는가?

## 타이밍

- [ ] 각 요소가 그 요소를 가리키는 단어에 나타나는가? 먼저 나오거나 늦게 나오지 않는가?
- [ ] 장면이 첫 그림과 함께 시작하는가? 제목만 떠 있는 시간이 길지 않은가?
- [ ] 아무 시점으로 넘겨도 같은 화면이 나오는가? 되감아도 깨지지 않는가?
- [ ] 빠르게 재생해도 끊기지 않는가?
- [ ] 말이 지나간 요소는 쉬거나 치워졌는가?

## 화면

- [ ] 글자 위로 선이나 점선, 화살표, 입자가 지나가지 않는가?
- [ ] 글자끼리, 글자와 그림이 겹치지 않는가? 전환 중에도 겹치지 않는가?
- [ ] 새로 나온 표시가 기존 요소에 가려지지 않는가?
- [ ] 글자가 테두리나 패널 밖으로 넘치거나 잘리지 않는가?
- [ ] 갑자기 튀거나 툭 끊기는 움직임은 없는가? 되풀이되는 동작도 매번 부드러운가?
- [ ] 비교 대상은 나란히 있는가?
- [ ] 바뀌는 글자에 바뀜 효과가 있는가?
- [ ] 비유의 모양과 비율이 알아볼 만한가?
- [ ] 흐림, 가림, 빛남 효과가 의도한 쪽으로 작동하는가?
- [ ] 3D 장면에서 시점을 돌려도 글자가 입체를 따라가는가? 3D를 쓸 수 없을 때 2D로 나오는가?

## 실행

- [ ] 실행 중 오류가 나지 않는가?
- [ ] 장면의 구간이 끝나면 장면이 거둬지는가?
